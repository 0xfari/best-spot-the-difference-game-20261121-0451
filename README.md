The Clockmaker's Attic — a spot-the-difference game: two near-identical pictures side by side in three original rooms (a clockmaker's attic, a garden shed, a harbour café), 8 differences each, with hints, a timer and a score. Click a difference to mark it; find them all before time runs out.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080
